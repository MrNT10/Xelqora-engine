BEHIND THE SCENES

HOW IT
WORKS (SO FAR).

Curious how it works? Here’s what’s in the prototypes and what’s still on the drawing board. No pretending unfinished features are done.

01 — CORE
X / C++20

Start with a reliable foundation.

Core 2.0 explores lifecycle management, vector and matrix maths, fixed timestep scheduling and portable CMake builds. Its prototype has previously passed GCC and Clang test cases in a development environment; native Windows verification remains pending.

Explore repository ↗
02

Rendering systems RESEARCH

WebGL2 procedural demos today; future renderer abstractions, scene materials, ray effects and cross-platform backends are goals.

03

Physics and simulation EXPERIMENTAL

Browser physics experiments explore collision behaviour and fixed-step timing. Native integration is not complete.

04

Super resolution PLANNED

Xelqora Super Resolution (XSR) is a research direction. The browser rendering lab includes a WebGL2 port of AMD FSR 1.0 (spatial EASU + RCAS); FSR 2/3, frame generation and neural upscalers are not included.

05

Audio and assets PLANNED

Future work includes audio playback, asset loading, error handling and packaging workflows.

06

Release engineering IN PROGRESS

Automated tests, cross-platform builds, transparent release notes and an eventual stability-focused LTS channel.
